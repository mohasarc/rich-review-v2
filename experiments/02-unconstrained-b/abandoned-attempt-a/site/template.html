Say it back

  

    

      
1. A new host builds a LocalDaemonTransport for a health dashboard and never passes a purpose. How long does ping wait?

      
Answer250 ms. Only responseTimeoutPurpose: "status-observer" selects the 100 ms value, and it is chosen where the transport is composed, not per request.

      
2. Someone sets output.inlineRawBytes to 1 KiB in DaemonPolicy. Which stores change?

      
AnswerBoth OrderedCommandOutput (CLI capture and worker execution) and DaemonCompletionSpoolStore (daemon). Before #131 they had separate constants with equal values.

      
3. A test passes outputInlineBytes: 0 to LocalDaemonTransport and sends a single 64 KiB record. Does a client spill file appear?

      
AnswerNo. The adapter raises inline capacity to 64 KiB, and a record spills only when stored bytes exceed inline capacity.

      
4. Which single decision here changes what a caller can observe?

      
AnswerD5: when the one reattachment fails, the rejection now carries that attempt's error instead of the original close.

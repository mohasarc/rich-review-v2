## Declared choices

- Role framing: Reader recalling decisions before checking source, then critic checking what the explanation failed to teach.
- Box lenses: Static ownership, runtime ownership, caller authority, lifecycle/failure boundaries and test witnesses.
- Opening style: Concrete findings followed by the complete comparison table.
- Shape: One 42-row table with sealed recall records and a source appendix.
- Navigation: Experiment order; each row links its page, original recall and supporting source finding.
- Trust posture: Page observations, source inference and authors' recorded executions are distinguished. No scores, verdict controls or claim of an exhaustive semantic audit.
- Persona: One serial reader of overlapping subjects. This is not a set of independent fresh-human trials.
- Representations used: Rendered browser text, selected interactions, one inspected desktop screenshot, prose and a Markdown table. The video was read through its wrapper and transcript.
- Importance rule: Surface choices that change authority, observable failure, ordering, identity or what an assertion witnesses. A complete-layer omission is distinguished from a deeper-only revelation.
- Inputs used (beyond bundle): Finished earlier pages and their Entry point/Kind/Subjects metadata; the local pr-127/pr-131/pr-148 bundles; exact git objects from the read-only stack worktree; pinned architecture/policy plans. No external research.
- Tech: Playwright, a temporary localhost static server, Python, git read operations and Markdown. No symnav build or test run was needed.
- Built on earlier experiment(s): Read 01–37 as critique subjects. Reused no implementation or critique findings. Earlier critiques, author runbooks, author execution records and the prior v1 project were not consulted as guidance.

## What I tried

Read every finished page's visible decision inventory before external source, sampled descents, wrote 42 recall records, and sealed their captures before opening the diffs. Then checked shared subjects once and compared them with each recall. [The census](census.json) freezes completion at 06:30:56 +03:00; later completions are outside this pass.

The table flags deeper-only host policy inputs in 12/23/29 and the unused-timeout qualification in 25. Independent checks also found wrong first-owner claims in 01/22, a nonexistent old-test edit in 01, and overlooked migration rationale in several #148 pages. Other misses concern parent-side validation, fixture casts, lost disk stimuli, clock-guard scope and protocol-field selection.

The initial page-text capture hid preformatted source, but some table-formatted excerpts remained visible. I kept that limitation explicit. Interactive routes and source audits are bounded; no “no surprise observed” entry is a universal compliance claim. [Source extent and evidence](source-check/evidence.md), [blind-phase notes](captures/blind-phase-notes.md), [verification](verification.json).

## What I would drop

The repeated small misses make the long table harder to read; I kept them to preserve one result per page. A second pass should use independent readers and fewer shared subjects per reader. The raw control inventories are useful provenance but poor reading material.

## What I would do next

Promote the four observed surprises into their complete layers, correct the source-backed factual claims, and have a new reader attempt the same recall exercise without seeing this critique.

# Reading protocol

This experiment recombines the reader/editor angles for **PR #148 only**. It does not repeat the parents' whole-cohort studies. The reading cohort starts with the ten finished direct #148 teaching pages: 03, 06, 08's #148 portion, 12, 18, 23, 27's #148 portion, 29, 35 and 50. Reading 49's full declarations revealed four documented #148 copies (original/revised 23 and 29), plus its focused report; these were added before sealing. Stack-wide pages and 49's other-subject comparisons are outside this bounded comparison. The final cohort has fifteen reading surfaces in eleven experiments.

The agent first read philosophy.md, then the playbook, then root README metadata (entry point, kind, subjects) through experiment 55. That scan exposed earlier summaries, including optional policy in 23 and fixture reach in 27. The brief itself also carried prior findings. Selected #148 README declarations were then read. Therefore this is an **informed, sequential agent reading**, not an unfamiliar-human or independent blind study.

1. Render each documented #148 surface in numerical order. Save its visible text and identify its complete layer. Read the entire declared layer, not just the first screen. Record recalled decisions and questions before inspecting implementation.
2. Follow selected explanatory descents, recording exact parent/child text. The rendered text may contain inline source snippets already authored into a page; those are page exposures, not an independent source check. Do not open independent git content or the input diff before sealing recall.
3. Save recall plus hashes. The seal establishes chronology and subsequent byte stability, not independence or exhaustiveness. Then read parent critiques 54/55 as attributed leads and inspect #148's supplied PR/diff and pinned git context. Pin base ba53c8e1662fd86d198b95321c90d9c9bef10184 and head 20838f8dbf413e04767543eb2380d0d114da6c60. Contributor guidance was read before the seal; it is disclosed context.
4. Build one table with one row per documented surface. Distinguish recalled learning, source-phase corrections/additions, editorial devices, declared scope and witnessed parent/child surprises. A recall omission never implies the text appears nowhere. “None witnessed” never certifies rule 4. Source interpretation is not execution; producer recordings are not reruns here.

The complete critique is the introduction plus **all fifteen table rows**. Its opening is an index, not a smaller complete critique. Receipts contain quotations and source excerpts for claims already present in the table; they add no separate findings register. Missing, repeating and promising are editorial dimensions within rows, not rankings of artifacts or implementation verdicts.

Only decisions that change a prediction about ownership, accepted input, failure timing, replay, credentials, retained state, or test stimulus/oracle qualify as consequential. Additional spellings or numeric fidelity alone do not create a rule-4 finding. A named category is not always a disclosed condition or consequence. Declared narrow scope is recorded separately from hidden depth.

Browser tools are Playwright from /tmp/rich-review-05-browser and local Chromium/Chrome. They are tooling, not evidence of teaching quality. No symnav build, runtime execution, web research, or failed-v1 material is used. Original experiments and symnav worktrees remain untouched.

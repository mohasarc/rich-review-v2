## What I tried

Considered rigid-body collision physics, then chose deterministic protocol responses: a checksum failure is a predicate, not an elastic force. Every particle encodes a byte, message, record, identity or diagnostic trace; there is no ambient particle field.

The first instrument could explain the append barrier but could not hold it. Added a held-append condition tied to a real promise-gated receiver probe. Browser checks caught an off-by-one visual arrival at the final byte and an unlabeled-role accessibility issue; both were corrected. Screenshot inspection also corrected a lifetime scene that said “await manifest” despite retained records, and a conflicting-identity label that incorrectly suggested the original work had failed. No implemented representation was abandoned. The initial failed browser receipt is retained.

## What I would drop

The repeated empty capture slots in the identity scene add less than its single accepted-entry collision. The large two-process instrument also costs vertical space, and its full geometry requires horizontal scrolling on a phone.

## What I would do next

Ask an unfamiliar reader to predict what survives a disconnect, trace expiry and acknowledgement, then compare with an ordinary sequence diagram. No human comprehension trial was performed here.

## Visual-variable legend

| Variable | Meaning | Limit |
| --- | --- | --- |
| Violet circles | Control messages: acceptance, manifest, end | Letter glyphs identify the selected control; not actual serialized shapes |
| Cyan squares / amber triangles | stdout / stderr records | Numeric labels, not color, carry sequence identity |
| Tiny colored dots in Frame | One dot per actual encoded byte: prefix, header, raw payload | Spatial grid is invented; 186-byte fixture is real |
| R7 / T1 / 0…3 | Request, transfer and record identity | Fixed fixture identifiers, not production values |
| Straight outbound / curved return trails | Original delivery / fetch, reattachment or acknowledgement | Direction carries mechanism; lengths and travel times have no protocol meaning |
| Dock, fuse, coral rebound | Append completes, matching ledger entry is reused, or validation rejects | Rebound is never a real response packet; it does not fail the original accepted entry |
| Enclosures and filled slots | Process boundary and ownership of stored records | Grouped module geometry is lossy; the package boundary is shown separately |
| Fading dashed halo | Disconnected diagnostic trace expires | Fade is an analogy for a discrete callback; no gradual spool eviction |
| Empty server spool + retained R7 | Ack cleanup and retained ledger bookkeeping | Normal cleanup succeeds in this recording; source also records cleanup errors |

The compact on-page legend and local analogy notice accompany the instrument. Fixed timing, geometry, illustrative transitions and source-walk checkpoints are explicitly identified.

## Libraries considered and used

Used [PixiJS ParticleContainer](https://pixijs.com/8.x/guides/components/scene-objects/particle-container) to batch byte/trail marks and its scene graph for labels and boundaries. Used [GSAP timelines](https://gsap.com/docs/v3/GSAP/Timeline/) for playback, seeking and interpolated transitions; MotionPathPlugin supplies trajectory interpolation. Versions, notices and licenses are bundled locally.

Considered [Matter.js](https://brm.io/matter-js/docs/classes/Collision.html), but physical momentum would invent scheduling and collision semantics. Considered Three.js and regl: their depth/shader work offered no benefit for this planar ownership lesson. No custom animation clock, physics engine, diagram router or graph layout was implemented.

## What the weird form taught better or worse

Keeping two particles on the client side when the connection disappears makes partial capture tangible. Fetching only the remaining ordinals distinguishes transfer recovery from execution replay. Holding a particle outside its slot while the offset stays fixed expresses the append barrier. Letting only the halo disappear makes the trace/spool/ledger lifetime split visible in a way a single “completed” state obscures.

The form is worse at wire-field syntax, exception taxonomy and rationale. Those need terse text and receipts. A conventional sequence diagram is more compact and requires less legend learning. These are design judgments, not measured comprehension gains.

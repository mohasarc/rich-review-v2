Read the size carefully.

The survey includes all 356 text paths touched by the supplied stack, including files later removed. It omits untouched code and binary files. Each skyline compares that physical path with main using Git with rename detection disabled: a move is visible at both addresses. The cyan roads use a separate, rename-aware comparison with the preceding PR; they show selected cross-district file moves, not all responsibility transfers.

Height is 0.55 + 0.4√(added + deleted lines) for standing paths; unchanged paths have a 0.55-unit stub. Square-root compression, parcel area, street routing and construction motion are illustrative. Facade concern and window roles are path-based categories; contracts may include executable validation, and support includes configuration and documentation. Nothing in height, windows or animation measures behavior, test coverage, runtime traffic or elapsed development time. Existing tests are source evidence, not reported passing runs.

R1
A source home is not the active call path

The topology has two independent axes: which package implements an object, and which process holds it. DaemonClient and its registry/transport/controller objects live in the host process. The coordinator is in the daemon process; the executor module is loaded by its worker thread. The shipped CLI still composes the app-local graph. The frozen digest constrains selected head bytes, not base-to-head behavior or equivalence with the package.

R6
Changing the clock owner does not restart the idle interval

The lifetime object sets the deadline at construction and on navigation acceptance. Queue-idle notification merely tests it. If work completes after the deadline, the same method can trigger shutdown without a new full idle interval. The follow-up plan adds both readiness-armed and completion-based alternatives as future behavior. The queue now defaults to a monotonic source; that is distinct from wall-based idle deadlines.

# Design record

The narrow lesson is lookup reachability versus caller-held promise lifetime. A reader acquires a reference, holds it across a clear, then lets old work settle while the new cache entry remains. The ritual gives each verb a distinct consequence; it has no timer, score, microphone, form, or response storage.

Read the five assigned READMEs in order. Borrowed 04's distinction between actual execution and injected collaborators, 23's complete outline and exact returns, 36's insistence on identity at a named observation surface, 37's independent depth access, and 53's physical-interaction caveats. No implementation or evidence reused. Also surveyed representation fields from 15, 17, 24, 26, 40, and 54–68. In particular, 53 already uses resistance for awaited release; 64 uses music for release order. Avoided both. This is a fixed, directed reference-holding exercise, not a spring, identity matrix, loom, replay timeline, or sound score.

Considered an eraser sweep: rejected before implementation because gradual erasure would misrepresent synchronous Map.clear and imply destruction. Considered a pressure threshold: rejected because no duration or pressure threshold exists in the code. A press causes the boundary immediately; keeping the pointer down merely allows inspection. Release advances an injected work completion. Both have single-step equivalents.

Library evaluation: XState v5 models seven stages plus holding and supports direct jumps with a canonical setup. GSAP + Draggable owns pointer/touch drag, hit testing, return motion and short visual state changes. Interact.js dropzones were viable, but would add a separate motion choice. Native drag/drop would require more touch handling; React gesture libraries would require an unnecessary framework. No graph layout or routing is needed: there are two owners and fixed lookup slots, not a general graph. No audio because hearing contributes no new fact here. All runtime code is bundled locally.

Primary documentation consulted: https://stately.ai/docs/transitions, https://gsap.com/docs/v3/Plugins/Draggable/, https://interactjs.io/docs/dropzone/. Versions are pinned, not claimed latest.

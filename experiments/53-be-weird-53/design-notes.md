# A spring between “empty” and “done”

The experiment is a **coupled displacement instrument**. The reader offers one motion to two return handles. Base follows the hand. While the injected project graph is pending, head follows an asymptote below the caller-settled mark and recoils on release. A project completion or error frees the head handle. An error is still a settled promise; its readout changes to rejected rather than presenting a successful return.

This is a visual and motor analogy, not hardware haptics. The hand/cursor mismatch is the sensory channel. Spring length is neither force nor runtime duration. The artifact says this beside both the opening metaphor and the bench. It does not simulate an event loop or a daemon.

## Changes during the attempt

- Considered friction-driven erasure, then rejected it before building: it suggests that clearing destroys work or depends on how long the reader rubs. Clearing is synchronous and old caller-held promises can still settle.
- Chose an independently controlled project latch so reader motion cannot accidentally cause a real semantic transition. The actual-state readout is authoritative even while the illustrative handle is at rest.
- Initial recorder drafts used an incorrectly shaped synthetic SymbolIdentity; inspection of the source helper corrected it to `{ file, segments: [{ name }] }`. These setup failures produced no published observations.
- The installed Playwright package expected a missing browser revision. The checks use the existing system Chrome in an isolated process. No shared browser session or server was touched.
- Source-range checking caught an excerpt ending immediately before the new project `await`. It now includes the full method, and a static assertion checks both await links.
- Touch cancellation, lost pointer capture, window blur and reduced-motion mode receive explicit handling so the physical metaphor cannot leave a stuck hand state.
- A repeat browser check sampled the track before a viewport resize had completed. Geometry now redraws in ResizeObserver before paint, and the check waits for layout frames. The final pass also resizes during an active pull. Both final checks pass; the initial receipts are retained under evidence/.
- A one-off final survey script reused its output-path variable in a README loop and accidentally wrote survey JSON over experiment 52’s README. I restored all 68 original lines from that worker’s complete new-file diff and verified the exact original Git blob hash, `bc7e96915b62be702e39ef6629787dd30b920df2`. The repair receipt is [census-restoration.json](evidence/census-restoration.json). Later survey writes use an explicit path asserted to belong to this experiment. No Symnav source was affected.

No full implementation was abandoned halfway. The discarded concept and corrected harness/source issues above are the negative results of this run. No educational effectiveness claim is made without a human reader.

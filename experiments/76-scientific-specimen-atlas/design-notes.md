# Working design

The narrow subject is selective reset: which state survives crossing a lifetime boundary?
PR 127 supplies six stable handles whose entries clear together; PR 131 supplies nested
recovery counters whose scopes differ. This is not a full inventory of either PR.

The visual form is an atlas of serial sections, not a microscope camera, contact-sheet
identity matrix, navigation loom, spring bench, circuit, or policy-distribution graph.
Common rows register persistent owner, resettable contents, and escaped/caller state.
Horizontal sections are discrete observation checkpoints, not measured time or memory.

Read: philosophy; playbook 1, 2, 3, 6, 7 (and surrounding context); the five required
READMEs 04, 23, 36, 37, 53. Surveyed representation fields in 60–73 and more of 62,
64, 68, 70. Reuse is methodological only: pinned receipts, controlled measurements,
explicit simulation boundaries, predict/reveal and dependable return navigation.
No earlier implementation, evidence bank, measurements or coordinates are copied.

Libraries evaluated against official documentation: Observable Plot, Vega-Lite, Tufte CSS.
Plot supplies the shared scales, repeated facets and SVG marks; Tufte supplies et-book
typesetting and figure/margin conventions. Vega-Lite could express the same grammar
but would add its runtime and selection model for a small number of DOM controls.
Quarto was considered as a notebook shell but no kernel or report pipeline is needed.
No graph layout, semantic zoom, animated routing or generated bitmap is required.

Pyramid surface: ownership move and preservation; six stores / keys / projection;
undefined vs sync throw vs rejected promise; successful versus failed refresh; clear
versus awaited release; escaped promise settlement; required delivery slice; nested
retry budgets; eligibility and incomplete-fetch limit; error provenance; test scope.
Specific rationale gaps must stay on that surface. Source excerpts only add fidelity.

Prior worker attempts left brief/harness/log files and no implementation; preserve them.
This attempt writes only within experiment 76. Queue/index/commit handling is left to
the campaign orchestrator.

## 2. The change (my words, <= 3 sentences)

PR #148 adds a public `DaemonClient` entrance (execute/control, Node-free type declarations, one lazily loaded runtime per client) to the `@symnav/daemon` package, and moves the request-routing, warm-result capture/transfer, recovery (single local fallback, same-ID reattach, offset resume) and lifecycle (start/status/stop, daemon clock, idle deadline) mechanisms plus 37 mechanism test files inside that package, with the host injecting paths, version, enablement, executor, readiness probe and optional policy. The shipped CLI is deliberately not switched over: it still runs on 38 frozen app-local mechanism copies, so the consumer switch is a later, separate change. Two old entrances close — telemetry's `Clock.now`/separate coordinator `now` input (replaced by a daemon-owned wall + monotonic `DaemonClock`) and the `@symnav/daemon/policy-testing` export with its lint gate — and several test observations are dropped or replaced along the way.

## 5. Questions the top layer left open

1. What do `execute` and `control` actually accept/return? Is `control` one method with start/status/stop verbs?
2. "One runtime per client, dynamically loaded from construction": what happens if that load fails — is the failure latched for the client's lifetime, retried, or surfaced per call?
3. Routing vocabulary: is "missing" the same as "absent"? What does "cold" do (run locally while a daemon starts? start synchronously?) and why do "recovering/starting" not trigger warmup? What does "observe" consist of (a ping/probe)?
4. What exactly is "authenticated retry-safe rejection" — which daemon rejections qualify?
5. What are the recovery-loop bounds (numbers), the status response timeout value, and does "bounded" mean attempts or time?
6. "Controlled warm result" vs "controlled warm failure": what does the host see (exit code, message)? Does a controlled failure ever fall back locally?
7. What is the "compatibility digest" a digest of — the frozen CLI copies vs package sources? Why would CRLF matter?
8. "The package has no internal production dependency": does that mean no workspace package deps at all (e.g., telemetry)? How does it relate to closing telemetry Clock.now?
9. Process token / instance / protocol: where does a client get the token; why can ping and graceful shutdown skip it (who can shut a daemon down without a token)?
10. "Queue idle can trigger an expired deadline immediately": in what situation — after long active navigation?
11. What runtime behavior, if any, changes for users at head, given the CLI is not switched? Is anything in #148 reachable from the shipped CLI?
12. What did the deleted duration assertions protect, and did the Windows forced-exit behavior change or only the test's expectation?
13. What are "capacity failures" and what messages do they carry?
14. What do "narrow coordinates" vs "full mutation snapshots" look like in registry equality?
15. "The focused run is bounded to six suites" (receipt header) — which six, and did anything fail?

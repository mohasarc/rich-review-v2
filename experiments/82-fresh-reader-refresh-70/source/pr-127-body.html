1 ## Context
2 
3 The [daemon architecture spec](https://github.com/mohasarc/symnav/blob/main/plans/005/daemon-architecture-functional-spec.md) assigns turn-scoped semantic-cache lifetime to core. Building on #126, this layer moves only cache lifetime out of TypeScript while preserving all six algorithms, key spaces, promise/value identities, and failure behavior.
4

76 ## Decisions
77 
78 - Chose one scope with six handles over one shared map, because the existing queries have independent key and value spaces.
79 - Chose `Map.has` before `Map.get` over truthiness checks, because `undefined` is a valid cached value.
80 - Chose synchronous cache clearing before project release over clearing after the await, because released semantics must be unavailable while release is pending or rejecting.
81 - Chose to begin the next turn only after refresh succeeds over clearing at refresh entry, because failed refresh must preserve the current successful turn.

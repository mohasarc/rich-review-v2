Make policy a required input.

The existing daemon-package snapshot replaces CLI defaults and optional thresholds. The mechanisms still live in apps/cli.

02
STATED
↗
Choose the clock by client purpose.

Status observation uses 100 ms; ordinary one-response calls use 250 ms. Execute admission has 5 s; accepted completion has no deadline.

03
STATED
↗
Keep two recovery allowances.

An authenticated accepted close can reattach execute. A known manifest can resume fetch. Defaults remain one each, with a fresh fetch allowance per execute attempt.

04
STATED
↗
Use one set of byte limits end to end.

Capture, spool, worker checks and transfer codec consume output policy; control framing has its own limits. Small results stay inline, larger ones spill.

05
STATED
↗
Sample memory from the same snapshot.

Resource derivation leaves the CLI. RSS hysteresis, worker heap, sampling cadence and the replacement circuit use required resource values.

06
STATED
↗
Route the quieter clocks and caps too.

Startup retries and ownership, stop, idle, drain acknowledgements, logs and traces all take policy. An unused startup-timeout option disappears. Intentional missing deadlines stay missing.

07
STATED
↗
Move small test knobs into adapters.

Seven new helpers translate legacy test inputs into validated policies. Runtime compatibility overloads disappear; new tests exercise custom values and preserved recovery. Users get no tuning knobs.

08
UNEXPLAINED
↗
A later completion can change the reported error.

After reattachment accepts, a malformed completion escapes as corrupt in the head. The base returns the earlier closed error. The PR does not request this difference.

09
UNEXPLAINED
↗
A numeric fetch allowance is not a fetch loop.

On clean EOF during result-fetch, the head fails after one fetch even with its resume allowance set to two. The new count does not grant another fetch on that path.

10
UNEXPLAINED
↗
Some test inputs and assertions change scope.

Local derivation cases are deleted. Spill fixtures and expected thresholds change; a transport adapter raises inline=0 to 64 KiB, so some cleanup cases no longer force disk storage.

UNEXPLAINED
↗
Enforce retirement with source-string bans.

The package meta-test adds retired constant names and optional-input spellings to a production-source exclusion list.

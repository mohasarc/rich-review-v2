The decisions you can see from here

Each card opens the same fact at higher resolution.

01 / PRESENCEStated

Make missing policy a type mismatch.

Output, resources, lifecycle, diagnostics and transport require their sections. Deeper readers and codecs gain required numeric parameters.

Reason: omitted composition must not recreate local defaults. ↘
02 / OWNERSHIPStated

Retire parallel tuning surfaces.

Remove the CLI resource-policy factory, 26 constant declarations, eight workspace option fields and the executor’s output-options argument. Keep the existing package schema.

Reason: one policy owner; test tuning gets separate adapters. ↘
03 / VOCABULARYStated

Name a purpose. Carry two budgets.

Add optional ordinary | status-observer purpose selection. Transport requires the existing delivery section with separate numeric reattachment and resume limits.

Reasons: distinct deadlines; a resume allowance per execution attempt. Loops are unseen. ↘
04 / SHAPE WIDTHUnexplained

A section is still a structural shape.

Most inputs ask for whole sections; idle lifetime asks for one field. Numbers have no unit, range or provenance brand. Slice width is not explained per consumer.

The types require names and primitive types; they do not establish snapshot origin. ↘
05 / DIRECTIONStated

Less configuration can mean more assignable values.

Required arguments remove omissions. Holding dependency types fixed, removing required memoryCapBytes widens the workspace record shape. Resource shapes are replaced.

Same stated consolidation decision; “removed” is not an assignability direction. ↘
06 / EXCEPTIONUnexplained

One new capacity remains optional.

StoredCommandOutput adds optional maximumRecordBytes, while its file decoder requires a number. Some formerly inferred inputs become explicitly annotated.

No reason found for that optionality; previous inferred types and defaults remain unseen. ↘
07 / TEST BOUNDARYStated

Put permissive construction in tests.

Seven new helper files, plus local wrappers, offer optional legacy knobs and policy unions. Twenty-three test files change; their assertions are outside this view.

Reason: small test thresholds without production compatibility overloads. ↘

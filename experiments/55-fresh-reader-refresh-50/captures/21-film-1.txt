The complete decision map.

Core retains; TypeScript interprets.

Source bytes, revision and project transactions, six cache handles, and request/session retention move to core. Language algorithms stay in TypeScript. Selection and failure boundaries are preserved.

Follow this boundary ↘
The CLI supplies a host module.

Syntax and canonical paths belong to CLI. Daemon loads the supplied executor URL and moves ordered bytes. Renderer formats lifecycle reports; telemetry keeps usage. Node-free declarations still lead to a Node runtime.

Follow this boundary ↘
Identity crosses every boundary.

CommandName travels beside argv; protocol generation advances to 5. Closed failure vocabularies and ordered guards own retry meaning: authenticate → ready → memory → queue → duplicate.

Follow this boundary ↘
Accepted work stays accepted.

Codec, validator, socket directions, lifecycle, execution, receiver and capture split apart. FIFO accepts once. Duplicate requests attach. Fetch and reattachment have independent budgets; append precedes offset advancement.

Follow this boundary ↘
Policy owns limits; sessions own lifetimes.

One daemon snapshot covers output, memory, retries, polling, diagnostics and deadlines. No user threshold knobs. Worker generations, sampled activity, clocks, registry identity and delivery barriers have explicit owners. Host-side policy is separate.

12export class CliInvocationCoordinator {

17  async execute(request: CliExecutionRequest): Promise<DaemonClientExecuteResult> {
18    const selected = this.selector.select(request.argv, request.cwd);
19    if (selected.route.kind !== "workspace") {
20      return this.executeLocally(request);
21    }
22    const workspaceRequest: CliExecutionRequest = { ...request, argv: selected.argv };
23    let workspaceRoot: string;
24    try {
25      workspaceRoot = await this.options.resolveWorkspaceRoot(selected.route.startDirectory);
26    } catch {
27      return this.executeLocally(workspaceRequest);
28    }
29    return this.options.daemonClient.execute({
30      workspaceRoot,
31      commandName: selected.route.commandName,
32      argv: selected.argv,

34      telemetryEnabled: request.telemetryEnabled,
35    });
36  }

38  private async executeLocally(request: CliExecutionRequest): Promise<DaemonClientExecuteResult> {
39    const result = await this.options

41      .execute({ ...request, executionMode: "cold" });

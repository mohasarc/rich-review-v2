Carry these six facts into every detail.
01 / STATE
Retain preparation; renew meaning.

Source bytes, file indexes, project membership, and a session live longer than one query. Six independent semantic caches clear on a successful new turn or before release. Publication is per backend index or project graph; there is no whole-pipeline transaction. Selection refresh still evicts omitted source bytes.

02 / HOST
The host knows the product.

The CLI classifies syntax, resolves the workspace and state path, supplies an absolute executor module URL, and writes output. The daemon owns routing and captures warm output. The renderer also formats lifecycle reports. Build rules enforce the final package surface.

03 / POLICY & IDENTITY
One owner for each rule.

Immutable policy sections cross process and worker boundaries. Values stay fixed for users. One command vocabulary, distinct failure vocabularies, ordered routing and admission guards, and code-derived retry safety replace scattered authorities. Generation 5 makes command identity mandatory.

04 / TRANSPORT
Finishing bytes is different from doing work.

Separate owners handle framing, validation, raw sockets, bounded lifecycle exchanges, accepted execution, and resumable result receipt. Appended records advance the resume position. Fetches keep transfer state; reattachments keep request identity but create fresh capture. Each has its own retry budget.

05 / DAEMON LIFE
Accepted work has a continuing identity.

The ledger deduplicates; one FIFO queue executes; delivery tracks the current stream; a generation manager fences old workers. Resources gate readiness and later turns. Activity uses explicit snapshots. Cleanup failure can be diagnostic while acknowledgement succeeds. Accepted failure never triggers local replay.

06 / CARRIED CHOICES
Preservation has a cost.

Idle time still starts at construction and resets on acceptance. Ledger eviction, startup silence, control-plane start readiness, endpoint relocation, new election, selection-aware byte retention, and readiness/completion idle changes are deferred. Tests lose or change some composed observations; the PR template also changes without a stated reason.

The code root chosen for the command. Nested repositories form separate boundaries.
Backend
The language-specific engine that answers code questions.
Snapshot / revision
A discovered set of files / the identity used to tell whether a file changed.
Turn
One refreshed opportunity to run a query. Prepared state may outlive it.
Ledger
The daemon's record of accepted requests and their completion states.
Spool
Stored output records waiting for delivery or acknowledgement; small output can stay in memory.
Generation
An identity for a worker lifetime, used to ignore reports from an older worker.
Cold / warm / fallback
Local execution / retained daemon execution / local execution after a recoverable daemon problem.
Facade / port / hook
A small public doorway / a limited capability interface / host-specific behavior supplied to a reusable base.
Admission / acceptance
Checks before taking work / the daemon's promise to own that request identity.
FIFO / backpressure
First accepted turn goes first / slow consumption makes the sender wait.

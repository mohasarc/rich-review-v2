05 / How this print was made

A relation, not a replay.

The probe takes eight observations from each of six caches. Every pixel asks Object.is(read A, read B). The two prints use the same procedure, each in its own build. Matching colors across prints do not mean shared memory.

Cache contents are read through TypeScript’s compiled private fields. The return lens observes the query service’s public return values: promises for D/R/T/C/E, a node array for P. The backend adds async wrappers, so this is not a promise-identity claim about the backend API.

Real TypeScript workspace state and algorithms run against target(); missing();. Only refresh failure and project release scheduling are controlled. Separate small probes use injected state to isolate rejection and release ordering. No production source is edited.

Check queue defaults, composition and elapsed reporting

The base queue defaults to Date.now; the base process already passes a monotonic callback. The head queue defaults to NodeDaemonClock and records monotonicNowMs(); head composition passes its clock. NodeDaemonClock uses performance.now for monotonic time and Date.now for wall time.

The queue stores startedAt; it does not itself calculate elapsed time. The activity projector reports Math.max(0, nowMonotonicMs - startedAt). The backward-wall-clock question identifies an input-domain exposure, not a reproduced negative duration or expiry failure. The A1 descent additionally names wall-clock grace/idle use and a separate worker clock; these remain later qualifications. Clock ownership is stated intent; this narrow study does not separately audit the reason for every clock or removed parameter.

01

Authority / required input

The circle crosses a source boundary.

Before, the supervisor received a CLI-local five-field resource policy plus a separate optional interval and two restart constants. The terminator took two defaultable numbers. The registry owned a 15-second constant. After, each receives an existing package-defined section.

The square stays on the CLI row because #131 changes value authority, not the source home of these mechanisms. The triangle locates the test call site; the shared override factory itself lives in the daemon package’s testing entry.

04

Test composition

The triangle supplies the same required input.

The new supervisor case constructs a policy with cadence 17 and RSS thresholds 103 / 102 / 101. The test-only terminator subclass converts numeric parameters into a validated shutdown section. The registry subclass preserves its older platform/rename call shape by supplying the startup section.

withOverrides merges into the complete policy and calls fromSerialized. Zero cadence and equal hard/soft RSS thresholds fail validation. A type-level required input and a validated value are separate guarantees.

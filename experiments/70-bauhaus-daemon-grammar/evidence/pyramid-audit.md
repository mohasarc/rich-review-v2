The source book contains full frozen files for auditing. Those files naturally contain unrelated code, and are not an additional authored explanation layer. The PR body receipt similarly preserves the supplied wider PR context without turning it into an unannounced lesson.

Rationale search boundary: supplied PR body and six commit messages; relevant repository/spec text in `repo-rules.md`; the pinned head policy record; source and focused tests. The implementing conversation was not supplied. The record states why inherited values exist; that is not a reason for selecting a whole section over a minimal projection, retaining `graceMs`, or deleting a particular test row.

The visual analogy is explicitly schematic next to the figure. Circle area has an exact field-count mapping; geometry otherwise does not claim call order, memory identity, test frequency, dependency count or elapsed time. The separation view explicitly suspends the alignment/overlap interpretation. The two repeated shapes for a policy section are notation instances, not two policy objects.

Who finishes before whom: cache turns and release, played

#127 hands the six semantic caches' clearing to core and makes release finish only after project cleanup finishes. Below, recorded runs of #126 and #127 play as a music box: see and hear the order in which owners clear, settle and reply.

Read it as a music box. Each owner is a row of tines. The drum turns one recorded event per step. A promise still pending is a held note. When a caller finishes while something it started is still held, the two notes clash.

lossy Steps are order, not time. Pitch is assigned per owner, not measured. “Clash” is this page's rule for “settled before its own work settled”.

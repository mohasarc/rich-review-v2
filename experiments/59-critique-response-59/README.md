## What I would drop

The full thirty-row crosswalk is an audit annex; it should not become another required PR reading route. Keeping the full source bank beside both layouts is useful for a portable review, but most readers only need the few witnesses attached to their uncertainty. The stricter diagnostic queue/history parent finding is less decisive than the child-retry and shutdown-budget counterexamples.

# Unfinished SEAMS shell

This directory preserves the previous unfinished UI found in this assigned experiment folder. Its HTML referenced missing overworld, level, codex, and app scripts and included a score placeholder. It is not the delivered game.

The final artifact is [Keep the Turn](../game.html): five reversible puzzle boards, no scoring, complete open contracts, and pinned local evidence. Existing graph/stack extraction intermediates in the parent folder were left intact for provenance and are not loaded by the delivered artifact.

The new build independently extracts all 117 declared decisions from `inputs/stack/pr.json`; it does not consume the old board or decision-kind data. No other experiment folder was read.

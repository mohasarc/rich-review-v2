MECHANISM

Erase entries before project release can settle

Release synchronously empties all six caches, then starts and awaits project release. Old cached entries are unavailable while release is pending or rejecting. Clearing does not block new queries: a query may refill a cache during the wait.

STATEDThe PR says released semantics must be unavailable while project release is pending or rejecting.

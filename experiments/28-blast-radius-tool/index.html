04 / THE MEASUREMENT IS PART OF THE EXPLANATION

A reproducible count, with a visible blind spot.

What is counted

  1. Manually map every changed file to decisions and choose symbols that expose those decisions.
  2. Run symnav refs TARGET --all --full-lines --json at both pinned revisions.
  3. Union files across a decision’s seeds. Exclude all its seed declaration files and generated output; classify tests and fixtures separately.
  4. Rank by distinct production files. The default unions base and head paths, avoiding double counts and retaining the reach of deleted symbols.

Switching to “Usage” excludes import, export and type references. It still counts the backend’s static usage category, not executed calls. Adapter symbols only exist in head. “0” means no observed external files; “—” means this choice cannot be measured this way.
